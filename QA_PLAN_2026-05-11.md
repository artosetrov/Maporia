## 2. Тестовые сценарии (по флоу)

Severity: **S1** блокер релиза · **S2** серьёзный баг · **S3** мелкий · **S4** косметика.
Каждый сценарий = { precondition → steps → expected → check (DOM/console/network) }.

### A. Public discovery (без логина)

#### A1. Главная `/` — hero + top-cities dropdown
- Открыть `/`, дождаться idle.
- Проверить: hero рендерится, top-cities dropdown заполнен (RPC `get_top_cities`).
- Клик по любому городу → ожидаем `/map?city=...` или эквивалент.
- **Watch:** console errors, network 4xx на `/api/rpc/get_top_cities` (или прямой supabase rpc).

#### A2. Главная — поиск
- Ввести запрос в поисковую строку (например `coffee`).
- Subimit → проверить, куда ведёт (модал SearchModal vs /map?q=...).
- Empty state на бессмысленном запросе (`asdkfj1234`).

#### A3. Главная — табы/секции по kind'ам
- Переключить между Locations / Services / Experiences (если есть таб-навигация).
- Проверить, что карточки соответствующего kind отображаются, ссылка ведёт на `/id/[id]`.

#### A4. `/map` — карта + кластеризация
- Зум in/out, drag.
- Кластеры схлопываются/разворачиваются.
- Клик по маркеру → попап с превью.
- **Watch:** deprecation warning по `google.maps.Marker` (известный TODO, не S1, но фиксируем).

#### A5. `/map` — фильтры (FiltersModal)
- Открыть фильтр-модал.
- TYPE: multi-select — выбрать `location + service`, apply → URL `?kinds=location,service`, маркеры пересчитались.
- Категории: выбрать категорию из секции LOCATION_CATEGORIES + SERVICE_CATEGORIES.
- Счётчики обновляются (Booking-style `computeFilterCounts`).
- Swipe-to-close (touch на header) — проверить, что drag>80px закрывает, scroll списка не конфликтует.
- Reset — все фильтры очищаются.
- **Watch:** что счётчики и реальный результат совпадают.

#### A6. Глубокая ссылка `/map?kinds=experience` — проверить, что фильтр восстанавливается из URL.

#### A7. `/explore` — листинг
- Скролл, пагинация / infinite scroll.
- Карточки кликабельны.

#### A8. `/id/[id]` — карточка локации (kind=location, legacy view)
- Открыть любую location-карточку.
- Галерея: пролистать, открыть lightbox.
- Контакты: phone/website/IG/YT/TG — каждая ссылка ведёт куда надо (`tel:`, `https://`, `instagram.com/...`).
- Карта мини / адрес.
- Комменты: видны, паджинируются.
- **Watch:** `/api/google/photo` — должно отдавать 302, не стримить body (известная ловушка из памяти).

#### A9. `/id/[id]` — карточка service/experience (OfferPlaceView)
- Открыть service-карточку.
- Цена/расписание/duration/included_items/bring_items.

#### A10. Locked-блок / Premium gate

### B. Auth flow

#### B1. AuthModal (passwordless OTP)
- На любой защищённой ссылке (например, клик Save на карточке без логина) → открывается AuthModal.
- Шаг 1: вижу Google OAuth + email-input.
- Ввести email → Continue → шаг 2 (6 input-боксов).
- Resend cooldown 30 сек.
- Back-кнопка возвращает на шаг 1.
- **Получение кода:** Артём пишет код вручную в чат.
- Verify → сессия создалась, модал закрылся, исходное действие выполнилось.
- **Watch:** Supabase template содержит `{{ .Token }}` (если в письме только ссылка — баг конфигурации).

#### B2. Google OAuth — НЕ кликаю без подтверждения (займёт окно, выйдет из браузера). Только проверяю, что кнопка не disabled.

#### B3. Magic link fallback — открыть письмо, кликнуть ссылку → `/auth/callback` → сессия.

#### B4. Logout — из `/profile` → возврат на `/`, защищённые routes снова редиректят на AuthModal.

#### B5. Legacy `/auth/login` — открывается, форма пароля видна, но это deprecated path (не блокер если работает криво).

## 5. Открытые вопросы / risk зоны (где скорее всего сломано)

Из памяти, риск-области:
1. **Photo proxy** — если кто-то трогал `/api/google/photo`, легко вернуть стрим. Проверю первым делом.
2. **FiltersModal Booking-pattern** — переписали недавно, могут быть рассинхрон counter vs result.
3. **Multi-kind карточки** — secondary_kinds не матчится в фильтрах (известно), но проверю что primary работает.
4. **Stripe webhook** — был flaky (UNIQUE constraint, CHECK constraint). UI-уровень не задеть, но если в `/profile/billing` план показан неправильный — оттуда корни.
5. **Bundle size на `/profile` (159KB)** — медленный TTI на мобилке.
6. **`useUserAccess` дёргается multiple times** — гонки в auth-state.
7. **AuthModal OTP** — если в Supabase Email Template нет `{{ .Token }}`, UI с инпутами кода бесполезен.
