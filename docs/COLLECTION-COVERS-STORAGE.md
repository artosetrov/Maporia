# Обложки коллекций (Storage)

Загрузка обложки с компьютера (админ: новая / редактирование коллекции) сохраняет файлы в **существующий бакет** Supabase Storage **`place-photos`** в подпапке **`collections/`**:

- Новая коллекция: `place-photos/collections/temp/{uuid}.{ext}`
- Редактирование: `place-photos/collections/{id_коллекции}/{uuid}.{ext}`

Отдельный бакет создавать не нужно — используется тот же бакет, что и для фото мест. Лимит размера файла: 5 МБ. Форматы: JPG, PNG, WebP.
